The Problem

Infrastructure teams drown in alerts. The signal gets lost in the noise.

Raw alert floods create fatigue. Manual investigation takes hours. Confident wrong answers from black-box tools erode trust.

Before Pamawas

  • 12,300+ raw alerts overnight from Grafana, Prometheus, Loki
  • 2Alert fatigue - engineers ignore or mute notifications
  • 3Manual RCA takes hours - digging through dashboards, logs, deployments
  • 4No shared understanding - each engineer sees a different slice
  • 5Confident wrong answers from black-box AI tools

After Pamawas

  • 1~17 correlated incidents - time-window + service/label grouping
  • 2One morning digest - Discord, Telegram, or Email
  • 3Bounded LLM investigator pulls PromQL, LogQL, deployment data on demand
  • 4Every finding typed: FACT, LIKELY_CAUSE, HYPOTHESIS, UNKNOWN
  • 5Read-only - zero autonomous remediation, full audit trail

Quick Start

Get the Full Stack Running Locally

Three commands. PostgreSQL + all services via Docker Compose.

# Clone all components for repo in pamawas-ingest pamawas-correlator pamawas-investigator pamawas-reporter pamawas-scheduler pamawas-schema pamawas-infra; do git clone https://github.com/Pamawas/$repo.git done # Bring up local stack (PostgreSQL + services) docker compose -f pamawas-infra/docker-compose.local.yml up -d # Run migrations cd pamawas-schema && go run ./cmd/migrate # Start services (each has its own docker-compose or make target)

Principles

Design Principles

Every architectural decision traces back to these four constraints.

1

Alerts Are Evidence

100 alerts may represent one failure. Correlate before investigating. Group by time window + service/label overlap.

2

LLM Is the Investigator

Structure data first. Give the LLM curated context plus bounded tool access. Do not dump raw alert floods into the model.

3

Evidence Before Conclusions

Every finding typed: FACT, LIKELY_CAUSE, HYPOTHESIS, UNKNOWN. Honest uncertainty beats confident hallucination.

4

Read-Only First

Zero autonomous remediation. Query, correlate, explain, recommend. Controlled remediation is a later phase.
